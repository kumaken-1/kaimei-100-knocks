# 開明小を考える100本ノック

「子どもの事実から、授業と学校を決め直す。」を中心コンセプトにした、教職員向けの思考トレーニングアプリです。

正解・不正解を判定せず、100の短いケースを通して、次の視点を問い直します。

- 何のためか
- 誰が判断するのか
- 何を根拠にするのか
- 本当にその手段が必要か

## 公開ページ

https://kumaken-1.github.io/kaimei-100-knocks/

## 構成

- `index.html`: アプリ画面
- `css/styles.css`: レスポンシブデザイン
- `js/questions.js`: 100問のデータ
- `js/app.js`: 画面表示と操作
- `js/core.js`: 進捗・回答状態の処理
- `tests/`: データ・画面・ブラウザ検証

外部ライブラリを使わない静的サイトで、回答とメモは利用端末の `localStorage` に保存されます。児童名などの個人情報は入力しないでください。
